# TaskMate – Task Management App

## 1. Project Overview

TaskMate is a task management application designed to help users organize their daily activities, manage deadlines, and track task progress in one place.

The application provides a simple interface for creating, viewing, editing, deleting, and organizing tasks. It also includes a dashboard, Kanban board, calendar, analytics, and settings.

## 2. Problem Statement

Managing multiple tasks manually can lead to missed deadlines, poor organization, and reduced productivity. TaskMate aims to simplify task management by providing a centralized platform to organize tasks and monitor progress.

## 3. Objectives

- Create and manage tasks efficiently.
- Set task priorities and due dates.
- Organize tasks by status.
- Track task progress using a dashboard.
- View tasks through a calendar and Kanban board.
- Analyze task completion and productivity.

## 4. Features

- **Dashboard:** View task summaries and recent activities.
- **Task Management:** Add, view, edit, and delete tasks.
- **Kanban Board:** Organize tasks into To Do, In Progress, and Completed.
